# Secretary

[English](README.md) | 日本語

Obsidian の中に置く秘書。次のものからなる。

- 突然の依頼をひとまず置いておく**受信箱**
- 時刻に知らせる**リマインダー**
- Tasks プラグインの書き方の**期限**の見張り
- ほかのプログラムからの**お知らせ**
- それらを並べる**パネル**
- 1分ごとに見て知らせる**ハートビート**

ほかのプラグインやアプリには頼らず、これだけで動く。デスクトップ専用。

ほかのプログラム（スクリプト、GitHub Copilot CLI などのアシスタント）は、**受け口のフォルダ**に1件1ファイルのメッセージを置いて渡す。プラグインが受け取って、受信箱やリマインダーのノートに書き、お知らせとして出す。プラグインが外のプログラムを起動したり、ネットワークで命令を受け付けたりすることはない。

予定（時間の幅があるその日のブロック）は Day Planner と、その予定を知らせる仕組みに任せる。リマインダーは、ある時刻に一言知らせるだけのもので、何日先でもよい。

表示言語は Obsidian の言語設定に合わせる（日本語なら日本語、それ以外は英語）。

## 何をするか

- **受信箱に追加**: 1行の入力欄から、受信箱の末尾に `- [ ] 2026-11-20 10:32 内容` として足す。分けずに追加して、あとでまとめて仕分ける使い方を前提にしている。
- **リマインダーを追加**: 知らせてほしい内容を書き、日付（最初は今日）と時刻をカレンダーと時刻の欄から選ぶ。内容を `15:00 内容`（今日。その時刻を過ぎていれば明日）か `2026-11-21 09:30 内容` のように時刻から書くと日付と時刻に入るので、打つだけでも追加できる。欄の下に、いつ知らせるかが出る。
- **受け口**: ほかのプログラムが置いたメッセージを受け取る。決まりは下の「受け口」を参照。
- **ハートビート**: 1分ごとに（受け口とノートが変わったときはすぐに）見て、
  - 受け口のメッセージを、お知らせ・リマインダー・受信箱に振り分ける。
  - 時刻が来たリマインダーを、画面の真ん中に出して知らせる（下を参照）。
  - 設定した時刻（既定 9:00 と 16:30）を過ぎたら、受信箱の未整理と、期限を過ぎた・今日・明日が期限のタスクがあれば、一度ずつ知らせる。
- **期限**: Vault の中（設定でフォルダに絞れる）の、Tasks プラグインの書き方 `- [ ] 内容 📅 2026-11-25` で期限が付いた未完了のタスクを読む。完了（`[x]`）と取り消し（`[-]`）は数えない。期限を過ぎたものと今日が期限のものはステータスバーに、明日が期限のものも合わせてパネルに出す。明後日より先のものは「明後日以降 N 件」の 1 行にまとめ、押すと期限の近い順に開く。パネルの行を押すと、そのノートのその行が開く。期限を足したり変えたりすると、ノートが保存されたときにすぐ出る。読み直すのはそのノートだけ。内容の中のリンクは、表示される言葉で出す（`[銀行に電話](https://…)` は「銀行に電話」、`[[計画|予算]]` は「予算」）。期限（📅）のほかの項目（繰り返し、優先度など）は読まない。Tasks プラグインが入っていなくても動く。
- **パネル**: 右のサイドバーに、お知らせ、期限、今日これからのリマインダー（時刻を過ぎてもチェックの付いていないものは「過ぎた」を付けて先頭に）、受信箱の中身を並べる。明日以降のリマインダーは「明日以降 N 件」の 1 行にまとめ、押すと近い順に開いて、今日の分と同じように編集・完了できる。受信箱の行の **リマインダーへ** は、その内容を入れたリマインダーの欄を開き、追加すると行が受信箱から消える。受信箱の行は、クリックで内容を直せる（追加した日時はそのまま）。Ctrl+クリックでノートのその行へ飛び、右クリックのメニューには **編集**・**ノートで開く**・**リマインダーへ**・**完了**・**削除** がある。**完了** はほかの形で片付いた行にチェックを付ける（行は記録としてノートに残る）。リマインダーをクリックすると、追加するときと同じ欄で日付・時刻・内容を変えられる。Ctrl+クリックでリマインダーのノートのその行へ飛ぶ（行を消すときなどはそこで）。右クリックのメニューには **編集**・**ノートで開く**・**完了**・**削除** がある。**削除** は要らなくなった行をノートから消す（やったことの記録を残すなら **完了**）。消した直後の知らせの **元に戻す** で、行が元の位置に戻る。**完了** でチェックが付く。パネルやリマインダーの画面で完了すると、**元に戻す** の付いた知らせが少し出る。あとで気づいたときのために、リマインダーと受信箱の下に「今日完了 N 件」が出て、押すと今日完了したものが取り消し線で並び、それぞれ **元に戻す** でチェックを外せる（日付が変わると消える）。お知らせは「既読」で印だけが消え、行は残る。読んだがまだ片付いていないものに使う。「完了」で行が消え、「既読をすべて完了」で既読のものがまとめて消える。未読のお知らせは太字になり、あるあいだはパネルのタブに紫の点が付くので、パネルが隠れていても分かる。リボンの鈴のアイコン、ステータスバーのクリック、コマンドのどれでも開く。
- **ステータスバー**: 「お知らせ 1 | 次 15:00 車の保険を更新 | 受信箱 3」のように出す。

知らせる先は、Obsidian の中の通知と Windows の通知の両方（Windows の通知は設定で止められる）。

リマインダーは見落とさないように知らせる。時刻になると、Obsidian が前に出て短い音が鳴り、片付けるまで画面の真ん中に出たままになる。**完了** でその行にチェックが付く。**10 分後**・**1 時間後**・**明日**（同じ時刻）で時刻をずらせ、**日時を選ぶ…** では日付と時刻の欄で好きな時刻を選べる（内容も直せる）。ずらした時刻にまた知らせる。リマインダーのノートを打っている途中は、手を止めて数秒たってから知らせるので、書きかけの行で鳴ることはない。開いているあいだに時刻が来たリマインダーは同じ画面に加わり、Obsidian を閉じていて逃したものは、本来の時刻を添えて出る。出た瞬間に別のつもりで押したクリックやキーで片付かないよう、ボタンは出てから 1 秒は押せない（薄く表示される）。画面の外をクリックしても閉じない。閉じる・×・Esc で閉じても、残っていたリマインダーにチェックは付かない。パネルに「過ぎた」を付けて残るので、済んだらそこで **完了** を押す。前に出すことと音は、それぞれ設定で止められる。

## 受け口

ほかのプログラムからプラグインへ渡す方法（決まりの版 1。「フォルダ受け渡し形式 v1」と呼ぶ）。これが公開の受け渡し口で、送る側との取り決めはこの節だけ。プラグインは送る側を知らず、送る側もプラグインの中を知らなくてよい。

### 置き場所

既定は `%LOCALAPPDATA%\Secretary\queue`（Windows 以外では `~/.secretary/queue`）。設定で変えられる。Vault の外に置くので、送る側は Vault の場所を知らなくてよく、メッセージが検索や Tasks の一覧、Vault の git の履歴に混ざらない。

### 置き方

1件 = 1ファイル。UTF-8 の JSON で、名前は `.json` で終わる。

1. 隠しの一時ファイル（例: `.20261120-152300-123-copilot-1a2b3c4d.json.tmp`）に書き切る。
2. 同じフォルダの中で `.json` の名前に変える。

プラグインは `.` で始まる名前と `.json` 以外を読まないので、書きかけのファイルは見えない。名前は他と重ならなければ何でもよいが、時刻で始めると古い順に処理される。

### 中身

```json
{ "v": 1, "type": "notify", "text": "旅行の候補をまとめ終わりました", "source": "copilot" }
{ "v": 1, "type": "remind", "text": "車の保険を更新", "at": "2026-11-20T15:00" }
{ "v": 1, "type": "inbox",  "text": "図書館の本を金曜までに返す", "source": "m" }
```

| 項目 | 必須 | 中身 |
|---|---|---|
| `v` | ○ | 決まりの版。今は `1` だけ |
| `type` | ○ | `notify`: すぐ知らせ、パネルに完了まで残す。`remind`: リマインダーのノートに足し、`at` に知らせる。`inbox`: 受信箱のノートに足す |
| `text` | ○ | 1〜1000 文字。`notify` は改行も可。`remind` と `inbox` は1行にまとめる |
| `at` | `remind` のみ ○ | その PC のローカル時刻 `YYYY-MM-DDTHH:MM`（秒は付けてもよい）。`Z` や `+09:00` などの時差は付けない |
| `source` | | 送り主の名前（40 文字までの1行）。パネルと通知に出る |
| `quiet` | | `notify` だけ。`true` ならポップアップを出さず、パネルにだけ残す |

知らない項目は無視する（あとの版で項目を足せるように）。知らない `v` は受け取らない。

### 受け取ったあと

- 振り分けて、記録してから、ファイルを消す。消す前に Obsidian が落ちても、処理したファイル名を覚えているので（最近の 200 件）、二度は届かない。
- 形が違うものは、フォルダの中の `rejected` に移し、理由を通知とパネルに出す。パネルの「消す」で表示だけを消す（ファイルは残る）。1ファイル 16 KB まで。一度に処理するのは 50 件まで（残りは次の回）。
- Obsidian が閉じている間に置かれたものは、次に開いたときに処理する。`remind` の時刻を過ぎていれば、そのとき知らせる。
- 文は文字として表示するだけで、HTML や Markdown として解釈せず、リンクも開かない。

### PowerShell から送る例

```powershell
$dir  = Join-Path $env:LOCALAPPDATA 'Secretary\queue'
$name = '{0}-shell-{1}.json' -f (Get-Date -Format 'yyyyMMdd-HHmmss-fff'), [guid]::NewGuid().ToString('N').Substring(0, 8)
$json = @{ v = 1; type = 'notify'; text = 'バックアップが終わりました'; source = 'backup' } | ConvertTo-Json -Compress
New-Item -ItemType Directory -Force $dir | Out-Null
[IO.File]::WriteAllText((Join-Path $dir ".$name.tmp"), $json, [Text.UTF8Encoding]::new($false))
Move-Item (Join-Path $dir ".$name.tmp") (Join-Path $dir $name)
```

## リマインダーのノート

```
# リマインダー

- [ ] 2026-11-20 15:00 車の保険を更新
- [ ] 2026-11-21 09:30 申請の締め切りを確認
- [x] 2026-11-19 17:00 済んだもの
```

- 既定の場所は Vault の直下の `リマインダー.md`（英語の表示なら `Reminders.md`）。設定で変えられる。無ければ最初に追加したときに作る。
- 1行 = 1件。`- [ ] YYYY-MM-DD HH:MM 内容` の形の行だけを読む。日付のない行、ありえない日付や時刻の行は無視する。手で書き足してもよい。
- 時刻になると知らせの画面に出し（上を参照）、片付くまでチェックは付けない。知らせの画面かパネルで **完了** を押すと `[ ]` を `[x]` にし、時刻をずらすと行の日付と時刻を書き換える。読んだときと行が変わっていたら（その間に書き換えられた・行が動いた）書き換えず、そのことを画面に出す。
- Obsidian を閉じている間に時刻が過ぎたものは、開いたときに「（2026-11-19 17:00 の分）」と添えて知らせる。
- 取り消すときは行を消すか、自分でチェックを付ける。

## 受信箱のノート

```
# 受信箱

- [ ] 2026-11-20 10:32 図書館の本を金曜までに返す
```

- 既定の場所は Vault の直下の `受信箱.md`（英語の表示なら `Inbox.md`）。設定で変えられる。
- 未チェック（`- [ ]`）の行を未整理として数える。仕分けたら行を消す前提で、チェックを付けて残した行は数に入らない。

どちらのノートも、変わるたびに読み直すので、手で直してもすぐ反映される。

## リンク

リマインダー・受信箱・お知らせの本文には、Markdown の標準の書き方でリンクを書ける。パネルとリマインダーの画面では表示名だけを出し、押すとそこを開く。押して開くのはリンクの部分だけで、ほかの所を押せばこれまでどおり編集が開く。表示名がパスや URL そのもの（貼り付けたままのもの）なら、行を埋めないよう、ファイル名・フォルダ名かサイト名（`example.com/…`）だけを出す。ノートには完全なパスが残り、マウスを載せると出て、コピーでも完全なパスが取れる。

```markdown
- [ ] 2026-11-25 15:00 見積もりを送る [見積もり](<file://server/share/営業/見積もり.xlsx>)
- [ ] 2026-11-25 09:12 確認する <https://example.com/status>
- [ ] 2026-11-25 09:13 [[会議メモ|メモ]] を読む
```

- 受信箱とリマインダーの入力欄に、Windows のパス（`C:\…` や `\\server\…`）や `https://` の URL を貼り付けると、この形のリンクにして入る。文字を選んでから貼り付けると、それが表示名になる。エクスプローラーの「パスのコピー」で付く両端の `"` は外す。
- ウェブのページはブラウザで、ノートは Obsidian で開く。
- `file://` のリンクは、フォルダならエクスプローラーを前に出して開き、ファイルなら関連付けられたアプリで開く。後ろのボタンでパスをコピーでき、右クリックでも **開く**・**パスをコピー** が出る。
- リンク以外の所を押したときは、これまでどおり（リマインダーと受信箱は編集が開く）。
- ステータスバーと通知では、リンクは表示名だけになる。

お知らせや受信箱には、ほかのプログラムから届いた文も入るので、押しただけでプログラムが動いたり、知らないサーバーにつながったりしないようにしている。

- 確かめずに開くのは、マクロを持てない文書・画像・音声や動画の種類（PDF、`.docx` `.xlsx` `.pptx`、テキスト、写真など）とフォルダだけ。それ以外（`.exe` `.bat` `.lnk`、マクロを持てる `.xlsm` や古い形式の `.xls` `.doc`、`.iso`、知らない拡張子など）は、開く前に確かめる画面を出す。既定はキャンセル。
- `\\server\…` のリンクは、初めてのサーバーなら、つなぐ前にサーバー名を見せて確かめる。開くと Windows のアカウントでそのサーバーにサインインするため。一度つないだサーバーは覚えて、次からは確かめない。
- リンクとして開くのは `https://` `http://` `mailto:` だけ。ほかの種類（`ms-msdt:` `search-ms:` など、開くとプログラムが動くことがあるもの）は文字のまま出す。

## 同じことを何度も知らせない

受信箱の知らせは、設定した時刻ごとに一日一度。Obsidian を途中で開いたときは、過ぎた中で一番新しい時刻の分だけを知らせる（9:00 と 16:30 なら、13:00 に開くと 9:00 の分）。リマインダーはチェックを付けるので一度きり。知らせた記録はプラグインの `data.json` に日付付きで残し、日が変わったら捨てる。

## コマンド

| コマンド | 動作 |
|---|---|
| 受信箱に追加 | 入力欄を出す。Enter で受信箱に足す（変換中の Enter は変換の確定に使う）。 |
| リマインダーを追加 | 入力欄を出す。内容・日付・時刻がそろうまで（過ぎた時刻は不可）ボタンは押せず、欄の下に足りないものを出す。 |
| パネルを開く | 右のサイドバーにパネルを開く。 |
| お知らせをすべて既読にする | 未読のお知らせをすべて既読にする。 |
| 受信箱を開く／リマインダーを開く | それぞれのノートを開く。 |
| 今すぐチェックする | 受け口と2つのノートを読み直して、一覧を出す。 |

既定のホットキーはない。「受信箱に追加」と「リマインダーを追加」には、設定 → ホットキーで割り当てておくと速い。

## 設定

受信箱のノートのパス、リマインダーのノートのパス、受け口のフォルダ、まとめて知らせる時刻（空にすると知らせない）、期限を見張るかどうかと、見張るフォルダ（空なら Vault 全体）、Windows の通知のオンオフ、リマインダーで Obsidian を前に出すかと音を鳴らすか。打つと、ノートの欄は Vault の各フォルダに既定の名前を付けた候補を出し（既存のノートは出さない。選ぶとそこに追記されるため）、フォルダの欄はフォルダの候補を出す。ノートのパスを `.md` なしで書くと `.md` を補う。

## プラグインが持つもの

`data.json` に、設定のほか、お知らせ（最新の 100 件。超えたら既読の古いものから消す）、処理した受け口のファイル（名前・大きさ・時刻で、最近の 200 件）、受け取れなかったファイル（最近の 20 件）、今日知らせたものの記録、今日完了したもの（元に戻すため。日が変わったら捨てる）、リンクを開くのを許したサーバーの名前（最近の 200 件）を持つ。

## 制約

- Obsidian が開いている間しか動かない（受け口に置かれたものは、閉じている間も残る）。
- 知らせるのは、時刻を過ぎてから最初の確認（1分ごと）のとき。
- リマインダーの時刻は、その PC の時刻（ローカル時刻）として扱う。

## 注意

- 書き込むのは、受信箱とリマインダーのノート（行の追記、パネルやリマインダーの画面からのチェック・編集・削除・元に戻す）と、受け口のフォルダの中のファイルの削除と移動だけ。ほかのノートには書かない。
- 受け口のフォルダには、同じユーザーで動くプログラムなら誰でも置ける。届いた文は表示するだけで、中のリンクも押したときにだけ開く。文書などでないファイルと、初めてのサーバーは、確かめてから開く（「リンク」を参照）。
- Windows の通知は `Notification` で出す。ほかのプラグインが `Notification` を差し替えていると、このプラグインの通知もそこを通る。
