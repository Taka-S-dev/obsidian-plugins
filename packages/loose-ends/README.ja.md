# Loose Ends

[English](README.md) | 日本語

Vault の後始末の漏れを一覧にするプラグイン。ノートに画像を気軽に貼り、あとで本文から消したときに残るもの（使われない画像、切れたリンク、空のフォルダ）を見えるようにする。デスクトップ専用。

表示言語は Obsidian の言語設定に合わせる（日本語なら日本語、それ以外は英語）。

## 何を出すか

リボンの消しゴムのアイコンか、コマンド「Loose Ends: 一覧を開く」でタブに開く。種類ごとのタブに件数を添えて並べ、選んだ 1 種類だけを出す。最初は、件数のある最初の種類を開く。何も無い種類のタブは薄く出す。

調べるのは、開いたとき、**もう一度調べる** を押したとき、ここからごみ箱へ移した後だけ。裏で Vault を見張ることはしないので、普段の動作の負担にならない。上に調べた時刻を出し、**もう一度調べる** を押すと、調べている間はアイコンが回り、終わると「変わりはありません」「2 件減りました」のように変わった件数を添える。

- **切れた画像・ファイルへのリンク**: 先が無い埋め込み（`![[...]]`、`![](...)`）と、拡張子の付いたファイルへのリンク。押すとそのリンクの行を開く。
- **なくなった Vault の外のファイルへのリンク**: `file://` の URL を持つ標準の Markdown リンク（`[ラベル](<file:///C:/...>)`、`[ラベル](<file://server/share/...>)`、`<file:///...>`）のうち、先が無いもの。
  - 共有フォルダは応答が遅いことがあるため、**確認する** を押したときだけ調べる。
  - ドライブや共有ごとに、まずその根元を調べる。3 秒以内に応答の無い共有や、つながっていないドライブは「確認できなかった」としてまとめて出し、「無い」とは言わない。
  - 共有フォルダを調べると、Windows はそのサーバーに自分のアカウントでサインインする。ほかから持ってきたノートのリンクが知らないサーバーを指していることもあるため、初めてのサーバーは確認の前に名前を出し、許したときだけ接続する（既定は「ドライブだけ確認する」）。許したサーバーは設定の **接続を許したサーバー** に残り、そこで外せる。WebDAV（`\\host@SSL\...`）と `\\?\` `\\.\` には接続しない。
  - コードブロックとインラインコードの中のパスはリンクとして数えない。
- **どこからもリンクされていない添付ファイル**: ノート・キャンバス・ベース以外のファイルで、どのノートからもリンクされず、どのキャンバスのカードにも無いもの。画像はサムネイルで出し、ファイル名の下にフォルダ・大きさ・最後に変更した日（「3 か月前に変更」）を添える。
- **空のフォルダ**: 中のどの深さにもファイルの無いフォルダ。入れ子で空なら、いちばん外側だけを出す。
- **空のノート**: 本文に何も書かれていないノート（プロパティだけのものも含む）。リンクを押してできたまま書かなかったノートや、無題のまま残ったノートなど。どこかからリンクされているものは、消すとそのリンクが行き先を失うので、何か所からリンクされているかを添え、**すべて選ぶ** でも選ばない。ごみ箱へ移す直前に、まだ空かをもう一度確かめる。
- **まだ無いノートへのリンク**: あとで書くノートとしてわざと置くことが多いので、タブは最後に置き、最初に開くことはしない。

リンクの一覧（切れたリンク、Vault の外、まだ無いノート）は、1 行ずつ並べる。

- **行き先ごと**（最初）: 行き先ごとに 1 行にまとめ、何か所からリンクされているかを添える（多い順）。複数あるものは開くと場所の一覧になる。
- **ノートごと**: リンクのあるノートごとに 1 行にまとめ、件数を添える（多い順）。開くとそのノートのリンクが並ぶ。
- 上の欄で、行き先やノートの名前で絞り込める（空白で区切った語をすべて含むもの）。
- 最初は 50 件までを出し、残りは **さらに 50 件を表示** で出す。

添付ファイルは名前順・大きい順・古い順に並べ替えられる。リンクはされていなくても、ノートやスクリプト・設定のファイルにパスや名前が書かれているもの（Dataview の `dv.view("views/script")` など）は「使っているかもしれません」と書かれている場所を添え、**すべて選ぶ** でも選ばない。

## 開き方

- 添付ファイル、空のフォルダ、空のノートの行を押すと、ファイルエクスプローラーでその場所を開いて選ぶ。ファイルとノートはあわせて開く。
- 開くのは、Loose Ends のタブを置き換えない、最後に使っていた別のタブ（検索結果と同じ）。Ctrl を押しながらなら新しいタブ。
- 右クリックで、ファイルエクスプローラーと同じ Obsidian のメニューを出す。そこで削除や名前の変更をしたものは、一覧からすぐ外れる。

## 片付け方

添付ファイル、空のフォルダ、空のノートは、行ごとの **ごみ箱へ** か、チェックを付けて **選んだ N 件をごみ箱へ** で片付ける（**すべて選ぶ** もある）。

- ファイルを移すと空になるフォルダは、確認の画面に「空になるフォルダ N 件も一緒にごみ箱へ」として並べ、最初からチェックを入れておく（入れ子なら外側だけ）。Obsidian の設定の添付ファイルの置き場所と、それを含むフォルダは、空になっても残す。
- 移す前に、対象の一覧を出して確かめる。最初に選ばれているのは **キャンセル** なので、Enter で消えることは無い。
- 移す先は Obsidian の設定（ファイルとリンク → 削除したファイル）に従う。システムのごみ箱か、Vault の `.trash` フォルダになる。
- 移す直前にもう一度調べ、その間にリンクされた添付ファイル、ファイルが入ったフォルダ、何か書かれたノートは残す。

切れたリンクは自動では直さない。行を開いて、手で直すか消す。

## 候補から外す

わざと置いているもの・わざと残しているリンクは、どの種類でも行の **候補から外す**（目に斜線のアイコン）で一覧から外せる。リンクは行き先ごとに外す。外したものは件数に数えない。

外したものは、いちばん右の **外したもの** タブに、元の種類ごとに並ぶ。行ごとの **戻す** か **すべて戻す** で、いつでも一覧に戻せる。外す・戻すは、Vault を調べ直さずにすぐ一覧に反映する。

## 対象外

- 設定の **対象外のフォルダ**（1 行に 1 つ）の中は、どの一覧にも出さない。わざと置いている資料のフォルダなどを書く。
- コア機能のテンプレートが有効なら、そのテンプレートのフォルダも対象外にする。テンプレートの中のリンクは見本のことが多いため。

## 注意

- 「どこからもリンクされていない」は、Obsidian が把握しているリンク（ノートの本文とプロパティ、キャンバスのファイルのカード）で判断する。Vault のノートやテキストのファイル、.obsidian の CSS スニペット（snippets/*.css）とプラグインの設定（plugins/*/data.json、1MB まで）にパスや名前が書かれていれば「使っているかもしれません」と印を付けるが、コードの中で組み立てた名前など、それ以外からだけ参照されるものは、印なしで一覧に出る。ごみ箱へ移す前に中身を確かめること。
- 外のファイルの確認は、そのとき見えるパスで行う。共有フォルダの権限やネットワークの状態によっては、実在しても「確認できなかった」になる。

## 開発

```bash
npm test -w loose-ends
npm run build -w loose-ends
```

テストは Obsidian に依存しない部分（リンクの読み取り、パスの確認、空のフォルダと未使用の判定、文言）を `node --test` で確かめる。
