# Day Planner Notify

[English](README.md) | 日本語

[Day Planner](https://github.com/ivan-lednev/obsidian-day-planner) のタスク開始を見落とさないようにする Obsidian プラグイン。Windows・デスクトップ専用。

## 何をするか

Day Planner がタスク開始時に出す通知（`Task started: …`）を検知して、次を追加する。

- Obsidian のウィンドウを前面に出す（最小化・トレイ格納からも復帰）
- 短いビープ音
- タスク名と時刻を表示し、延期（+15分 / +30分 / +45分 / +60分）・ノートを開く・閉じるを選べるアラート
- 閉じるまで一定間隔で音とタスクバー点滅を繰り返す（2 回目以降はフォーカスを奪わない）

いつ通知するかは Day Planner が決める。このプラグインは時刻のパースやスケジュールを持たない。
アラートと音は OS の通知とは別に Obsidian の中で出すため、Windows の応答不可モードの影響を受けない。

表示言語は Obsidian の言語設定に合わせる（日本語なら日本語、それ以外は英語）。

## 延期

+N を押すと、今日のデイリーノートにあるそのブロックの開始・終了時刻を N 分後ろへ書き換える。
Day Planner がノートの変更を拾い、新しい開始時刻にもう一度通知する。スヌーズの代わりになり、タイムラインも実態に合ったまま保てる。

- 対象は未完了（`[ ]`）かチェックボックスなしの行だけ。完了・取り消し（`[x]` `[-]`）のブロックは触らない。
- タスク名と開始時刻で行を特定する。該当する行が複数ある場合や、日付をまたぐ場合は書き換えず、アラートに理由を表示する。
- 後続のブロックは動かさない。重なったら Day Planner のタイムラインで調整する。
- 選択肢は設定で変更できる（カンマ区切りの分数）。

延期した直後の通知に Undo ボタンが 8 秒間出る。押すと書き換える前の行をそのまま書き戻し、アラートを音・前面化なしで開き直すので、別の分数を選び直せる。
戻した直後に Day Planner が出す再通知は無視し、OS の通知も閉じる。
延期したあとにその行を編集していた場合は戻さない。

## 前提

- Windows 版 Obsidian 1.8.7 以降
- Day Planner の設定で Task Notification がオン（オフだと起動時に警告を出す）
- Obsidian が起動していること

## 設定

前面化モード（off / flash / front）、音のオンオフと音量、再通知の間隔と最大回数、延期の選択肢。

## コマンド

- テスト通知を送る
- 10秒後にテスト通知を送る（最小化して前面化を確認する用）

どちらも Day Planner と同じ経路の通知を発行するので、実際の動作をそのまま確認できる。

## 制約

- 同時刻に始まる複数のブロックは、Day Planner が 1 件しか通知しないため 1 件だけ反応する。
- Day Planner が通知文言（`Task started: `）を変えると検知できなくなる。

## 注意

- 延期はデイリーノートの該当行を直接書き換える。対象を特定できない場合は書き換えないが、大事なノートは Obsidian Sync や git などで履歴を残しておくこと。
- ブラウザの `Notification` を差し替えて Day Planner の通知を検知する。ほかのプラグインが同じ仕組みを使う場合、組み合わせによっては干渉する可能性がある。
